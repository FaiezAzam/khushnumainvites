# Khushnuma Invites
1. `npm install && npm run dev`
2. Set WhatsApp number, Instagram, Facebook, email in `lib/config.ts` (digits only, e.g. 923001234567).
3. Add designs in `lib/invitations.ts`; put MP4s in `public/videos`, thumbnails in `public/thumbs`.
4. Deploy free on Vercel. Tip: compress videos (H.264, under 3 MB, 720p) for fast mobile loading.
